修正 FileSystem 的文件名合法性判断与清理。拒绝点名称 . 和 ..、Windows 末尾的 ASCII 点或空格，以及 GENERIC 路径分隔符。Windows 保留名比较不区分大小写，检查扩展名前的基本名称时忽略其末尾 ASCII 空格；接受普通 CharSequence，不局限于 String。null 候选的合法性与保留名判断保持 false。

toLegalFileName 沿用各文件系统的字符、长度和字符集规则：先按既有长度策略截断，替换非法字符；Windows 去除末尾 ASCII 点和空格，去除后为空则使用一个替换字符。对仍为保留名或 .、.. 的结果，在前面添加替换字符直到不再保留；替换或加前缀使长度超限时，按既有保留扩展名的截断规则再次处理，Windows 再去掉末尾点和空格。最终结果必须合法，无法产生合法结果时拒绝。其他文件系统保留合法的末尾点和空格。

Windows 的替换字符不得为 ASCII 点或空格，即使当前候选无须替换也应拒绝；各文件系统继续拒绝非法或无法满足指定字符集约束的替换。保留默认字符集与显式字符集重载的一致行为。
