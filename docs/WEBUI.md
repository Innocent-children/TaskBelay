# 本机 WebUI

[中文](WEBUI.md) | [English](WEBUI_en.md)

配置适配器后运行 taskbelay webui start；status 查询本机实例，open 打开实例，stop 结束界面进程。源码安装方式见 README。界面读取 Core 保存的 Task，不建立第二份任务状态。

详情先展示目标、进展和剩余问题。实施思路、工作位置、明确限制和检查定义按需展开。实际执行、人工观察和代理声明分别标记；通过 get_run 读取输出。刷新实际状态后才判断结果适用性，保存状态不会冒充实时检查。没有重复的方案确认步骤。

累计投入持续展示。未设置的上限显示“未设置”；用户可明确调整预算，0 表示不设上限，消耗保留。时间类别可能重叠，不能直接相加。人工检查按钮只用于用户实际完成且能说明观察结果的 human 检查。重要需求取舍向编码代理给出真实决定。

列表支持分页、归档任务显示和 /tasks/{id} 直接定位，浏览器前进/后退保持选择。终态可归档或取消归档。已接受的回归失败继续显示为失败。取消保留文件，未确定执行须先处理；清除仅针对明确匹配的终态记录，不删除源码或工作树。

HTTP 限于本机 loopback，变更受 Host/Origin/CSRF 限制。界面明确请求完整任务详情，普通工具调用仍返回摘要。桌面宠物读取保存摘要，不表示实时活动或完成百分比。见[命令](COMMANDS.md)和[产品](PRODUCT.md)。
