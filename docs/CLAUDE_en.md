# claude Host usage

[中文](CLAUDE.md) | [English](CLAUDE_en.md)

Install the public manager with npm install -g taskbelay@latest and taskbelay install --host claude. The engineering contract is in source builds; published packages/stable records are unchanged. From the repository run node scripts/taskbelay-local.mjs install --host claude --yes. Preserve old data and choose a separate explicit TASKBELAY_DATA_DIR. Node.js >=24 is required; source builds need Go >=1.26 and pnpm >=11 <12.
