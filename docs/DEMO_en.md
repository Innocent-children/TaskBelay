# Engineering-task walkthrough

[中文](DEMO.md) | [English](DEMO_en.md)

Ask a configured Host for a concrete outcome, such as login-failure throttling while preserving authentication interfaces and stored data. First show understanding, root cause, the complete plan and verification arrangement; obtain explicit confirmation before implementing. The agent captures goals, non-goals, constraints and checks, alternating edits and tests as needed and retaining actual results and scope reasoning.

Add an independent requirement through revision and confirm the changed plan; unchanged goals and justified independent checks can remain valid. Related changes expire evidence and targeted gaps are rechecked. Unpredicted paths are review signals; forbidden content/unapproved dependencies are deterministic restrictions. Correct within authority first, asking only for material changed authority.

After interruption provide the Task ID and return to the original workspace. Read current requirements, results, failures and unresolved execution. Read an original run after response loss without rerunning. Deliver per-goal evidence and conclusions. The repeatable native script is tests/journeys/engineering.test.mjs. Scripted semantic inputs and real Host judgments are distinct; see [verification](PROJECT-STATUS_en.md).
