# 开发产物与验证证据

[中文](ARTIFACTS.md) | [English](ARTIFACTS_en.md)

开发规范、设计笔记和方法工具文件由代理按当前任务需要维护；它们不推动 Core 状态，也不提供另一套完成标志。旧阶段 artifact collect/prepare 入口已移除，Core 不要求维护流程文件来证明经过某个节点。

证据来自 Core 真实检查或明确用户观察，代理自述保存为 claim。验收结论关联具体目标与适用通过证据。运行输出、内容/条件摘要、失败尝试及恢复收据在本地保存，热记录压缩保留有效引用和累计消耗。宿主可以使用 OpenSpec、Spec Kit 或已有工程文档，但缺工具不构成虚构完成的理由。

完整结构见[架构](ARCHITECTURE.md)，生成的共享 Skill 位于四个宿主包且不依赖仓库外的共享目录。
