# Development artifacts and verification evidence

[中文](ARTIFACTS.md) | [English](ARTIFACTS_en.md)

The agent maintains specifications, design notes and method-tool files only when the task needs them. They do not advance Core or create another completion authority. Retired artifact collect/prepare entrypoints are removed; Core requires no workflow files as proof of passing a node.

Evidence comes from actual Core checks or explicit human observations; agent testimony is a claim. Acceptance conclusions reference goals and applicable passing evidence. Local records retain output, content/condition digests, failures and recovery receipts. Compaction preserves live references and cumulative usage. Hosts may use OpenSpec, Spec Kit or existing engineering documents; missing tools never justify invented completion.

See [architecture](ARCHITECTURE_en.md). Generated references are complete in all four Host packages and require no repository shared directory at runtime.
