# TaskBelay 产品定义

[中文](PRODUCT.md) | [English](PRODUCT_en.md)

## 目标与职责

帮助开发者使用现有 AI Coding Agent，在同等验收要求下以必要改动、合理验证投入和更少重复决定完成真实任务。代理理解需求、做技术判断和修改代码；本地 Go Core 将真实授权、实际变化和验证证据关联起来，决定还需修正、验证、等待还是用户决定。产品不提供编码模型、通用工作流或安全沙箱。

## 用户操作

描述期望结果、非目标与必要限制。代理先展示需求理解、根因、完整实施方案、责任划分、范围、验证安排与投入上限，用户明确确认后才实施。批准绑定具体方案；实质修订重新确认，普通进展沿用既有批准。每次新建 Task 先展示目录、分支和已有修改，并询问工作位置：当前分支、原目录新分支或独立工作树；没有默认选择。恢复已有 Task 使用原绑定目录。工作区准备、新会话与 Git 操作单独遵守授权。确认后实现与验证可交替。

修改前，宿主对所有仓库检查对应上游；先 fetch 核对远端，再根据实际授权决定是否整合。只有干净且可快进的工作区可安全整合；脏改动、分叉、失败和无上游均保留工作并明确说明。Core 保存最初基线与后续观察，不执行 Git 修改。长期任务在提交前复查。

Core 保存目标、接口/数据/依赖/设计约束、验收检查和授权消息引用。引用是宿主提供的审计依据，不是对话认证。程序观察文件内变化、Go 公开声明、依赖清单、数据契约文件、禁止路径和固定内容。预测路径和改动量只是复核提示；确定性禁止规则不能由语义评分覆盖。代理逐路径说明目标关联，逐约束说明依据与不确定性。优先在已有授权内自行纠正，需要改变授权或重要取舍时才交给用户。

## 验证、修订与恢复

Core 执行已授权的本地检查，保存真实进程结果。代理声明和明确用户检查单独记录，不能冒充自动执行。检查关联目标、定义、输入范围、所选环境条件和执行文件；默认覆盖全部已绑定仓库的 Git 可见输入，缩小依赖范围须说明依据。ignored 内容和外部服务不会自动成为已掌握条件。通过命令不等于证明验收结论，测试充分性和语义判断仍须技术审查。

需求修订保留未受影响的成果与证据；改变的目标、检查语义、相关约束、输入或条件使相应结果过期。仅调整超时、重试策略、完整套件标记或说明文字不使已有通过结果过期，其中超时在已批准上限内、说明文字的同步沿用原批准；重试策略、完整套件标记或超过批准上限的调整需要真实新决定。成本在任务生命周期内累计，包含执行、Core 调用和观察，以及单独标明的宿主报告分析、等待和 token；重规划不重置。时间类别存在重叠，不直接相加为总费用。额度不足不免除验收，缺口仍展示；必要时取得真实投入调整授权。

确认时区分确定不可预留和投入风险：某个必需检查的超时无法预留、执行次数不够或有效额度已耗尽时，先修正配置或取得具体投入决定；整套检查最坏超时与一次重试的合计只作估计风险提示。实际耗时、预留、未确定成本、剩余和下次需求分开展示。完整预算决定同时更新命令、次数、token 与相互重叠的 Core/宿主工作上限，保留累计消耗和原方案批准来源。相同检查与条件三次失败后需改变代码、条件或验证方法。

恢复读取最新授权、进展、有效/过期结果、失败尝试及未确定执行。操作身份在进程启动前保存，响应丢失不重跑。签名收据可以恢复真实结果；Core 或已记录的命令进程组仍活着时等待或查原执行。两者均结束但无收据时不推断通过，检查副作用后保存处理依据，不能安全重复的操作还需用户决定。未确定耗时保守计入。近期历史压缩不删除当前有效结果、未确定操作或累计成本。


每项实际改动关联已批准工作及必要性；预计路径不授予权限，明确允许/禁止路径由程序检查。已有适用通过证据应复用；相同条件失败重跑需新诊断依据，完整套件需说明定向检查的缺口。普通进度更新不能替换检查或降低验收。交付还需复核根因、职责、复杂度与验证投入，并明确重新设计是否仍会选择当前结构。仅已批准的回归检查可通过当前比较证据和用户决定接受列出的既有失败；失败仍显示为失败，内容或方案变化使例外过期。

## 完成与界面

全部目标已记录完成、当前范围复核有充分依据且无未解决不确定性、每项必需检查有适用通过证据或当前明确接受的回归失败例外、没有未确定执行时才能交付。逐目标保存验收结论和证据引用。完成与取消释放目录占用，保留文件；不自动提交、推送、合并、发布或删除资源。

本机 WebUI 展示结果、证据、剩余缺口、必要决定和累计成本；桌面宠物读取保存摘要，不代表实时代理活动。用户不需理解状态机或填写流程表单。TaskBelay 不拦截所有操作：结构化钩子只检查受支持路径，shell 与外部编辑在检查点观察。原工作区缺失或历史冲突时必须恢复原绑定；跨工作区迁移未提供。

## 支持与验收边界

当前升级属于源码能力，已发布包和稳定支持记录未改变。旧协议和旧数据库不兼容，不迁移、不自动删除。小型机械任务通常直接使用原生代理更合适。真实 Windows Core 场景验证、协议/存储测试、宿主适配器测试及真实宿主会话分别记录；未执行项目不能写成收益或支持事实。见[验证记录](PROJECT-STATUS.md)、[架构](ARCHITECTURE.md)、[命令](COMMANDS.md)。
