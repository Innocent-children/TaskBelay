# TaskBelay 产品定义

[中文](PRODUCT.md) | [English](PRODUCT_en.md)

## 目标与职责

帮助开发者使用现有 AI Coding Agent 持续完成真实任务：少重复交代和确认，能核对当前结果，中断后能继续，交付时说清完成情况和剩余问题。代理理解需求、选择方法和修改代码；本地 Go Core 保存唯一 Task，将实际请求、代码变化、检查结果和累计投入关联起来。

适合需要保存进展、复用验证结果或跨会话恢复的开发。小型机械修改和一般问答通常直接使用宿主即可；尊重用户明确调用或明确不使用的要求。产品不提供编码模型、通用工作流或安全沙箱。

## 开始与持续推进

用户描述期望结果和必要限制。代理读取项目规范和相关代码，说明原因、实施思路和验证安排，在已有授权与宿主权限内开始工作。Task 保存真实用户消息引用和请求，不要求额外批准每份计划。引用由宿主提供，Core 不能认证对话来源。

沿用用户指定或上下文明确的工作位置，展示目录、分支及已有修改。仅在位置不清楚、有冲突或需要新的工作区操作时处理必要选择。创建分支、工作树、会话、远端检查和整合按实际需要及授权执行，不是开工必经步骤。未检查远端时明确记录未知。恢复已有 Task 使用原绑定目录。

实现与验证可以交替。代理在完成一部分工作、发生相关变化、得到检查结果、遇到真实决定或交接时记录进展，不为每次编辑增加固定流程。工具默认返回当前需求、进展、改动路径、检查结果和投入；完整历史、文件指纹与运行输出按需读取。

## 调整需求与检查

用户目标和明确限制与代理的实施安排分开。调整实现思路、检查方法、预测路径和复核提示可以沿用原请求；改变目标、请求、明确限制或扩大已设投入上限，须引用实际新用户决定。修订只替换提供的内容，保留其他安排和未受影响的工作，不重置累计消耗，也不自动清除待回答的问题。

预测路径不构成权限。明确允许范围、禁止路径、固定内容和依赖限制由程序检查。未声明依赖限制时，依赖变化需要说明必要性和兼容影响；违反明确限制才直接阻断。宿主原生权限始终适用，结构化钩子只覆盖支持的写入路径，其他改动在检查点观察。

检查须服务于当前目标，记录真实命令、输入、条件和必要理由。缺省输入覆盖全部绑定仓库的 Git 可见内容；缩小范围须说明依据并包含实际依赖。忽略文件、数据库和外部服务不会自动成为已验证条件。通过命令不证明检查足够，代理仍要审查是否满足真实需求。

相关代码、目标、约束或执行条件变化使对应结果失效；无关工作和新增独立检查保留已有适用结果。相同条件的通过结果复用；无变化失败的重试须有新诊断信息，三次失败后改变代码、条件或方法。完整套件须说明当前缺口。不能通过弱化检查绕过失败。

## 投入与异常恢复

没有用户设置的成本上限时持续计量，不生成默认额度审批。正数上限分别约束累计执行次数、执行时间、Core 时间、宿主报告时间和 token；零表示未设置。扩大或取消已有上限需要真实用户决定。实际、预留、未确定成本分别显示；不同时间类别有重叠，不直接相加。预算不足不能免除验收。

执行前持久化操作身份和预留，结果保存后再返回。响应丢失先读取原操作；恢复已有收据不重跑命令。原进程或命令组仍运行时等待；已停止但结果缺失时检查实际副作用，保留未知结论。不能安全重复的操作需要实际用户决定。历史压缩保留当前结果、未确定操作和累计成本。

## 交付与界面

交付前查看实际改动，说明是否解决原问题、责任是否合适、复杂度与验证是否适度，以及是否仍会选择当前结构。所有目标有完成结论、必需检查有适用结果、没有未确定执行或待决定事项时才能完成。代理声明不能冒充执行，人工结果必须来自用户实际检查。

已有回归失败可以通过当前真实失败、比较结果和用户明确接受记录例外；验收检查不能豁免。例外只在相关结果仍适用时有效，失败继续显示为失败。交付明确列出实际通过、失败、未执行和未知项，不把受阻任务描述成完成。

本机 WebUI 优先展示结果、剩余问题和投入，实施与检查细节可展开，不提供重复的方案确认步骤。完成、取消和归档保留文件，不自动提交、推送、合并、发布或删除资源。桌面宠物读取保存摘要，不代表实时代理活动。

## 支持与验收边界

当前修改属于源码能力，公开包和稳定支持记录由独立发布流程决定。旧协议和数据库不兼容，不迁移或自动删除。覆盖正常开发流程、常见失败和已发生问题，不为假想的罕见组合扩建设计。

Core 实际执行、脚本提供的用户与语义输入、适配器测试和真实模型会话分别记录。源码测试不能证明用户介入、总时间或成本已经降低；这些收益需在相同任务和条件下比较原生代理、简洁提示词与完整插件。未执行的对照如实标明。见[项目状态](PROJECT-STATUS.md)、[架构](ARCHITECTURE.md)和[工程控制](ENGINEERING-CONTROL.md)。
