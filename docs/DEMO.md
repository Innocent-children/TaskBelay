# 工程任务演示

[中文](DEMO.md) | [English](DEMO_en.md)

向已配置宿主提出具体需求，例如增加登录失败限流并保留公开接口与已有数据。代理说明原因、实施思路和相关验证，在原请求授权内开发。调整方法无需重复确认，改变用户目标或明确限制时才取得实际新决定。

调整方案或增加检查时沿用当前请求；用户增加新目标时记录实际新决定。未受影响的目标与检查结果保留，相关代码变化后只补充所缺验证。预测外路径需要解释，违反明确路径或依赖限制会阻断；优先在已有范围内修正。

中断后提供 Task ID，返回原目录，读取当前需求、成果、有效结果、失败及未确定执行。响应丢失先读原 run，不重新运行。最后逐目标展示当前证据与结论。实际可重复脚本是 tests/journeys/engineering.test.mjs；脚本语义输入与真实 Host 判断须区分，见[验证记录](PROJECT-STATUS.md)。
