# 工程任务演示

[中文](DEMO.md) | [English](DEMO_en.md)

向已配置 Host 说明一个明确结果，例如保持认证接口和数据结构不变，增加失败登录限流。先展示需求理解、根因、完整方案与验证安排，取得用户明确确认后再实施。代理建立目标、非目标、约束与相关检查，在需要时交替修改与测试，保存真实结果和范围判断。

修订方案增加独立结果，展示修订并重新确认；未变化的目标与依赖范围明确的检查仍可保留。相关代码变化后检查过期，代理针对缺口重跑。计划外路径触发复核提示，禁止内容或未授权依赖触发确定性限制；优先自行修正，重要授权变化再询问。

中断后提供 Task ID，返回原目录，读取当前需求、成果、有效结果、失败及未确定执行。响应丢失先读原 run，不重新运行。最后逐目标展示当前证据与结论。实际可重复脚本是 tests/journeys/engineering.test.mjs；脚本语义输入与真实 Host 判断须区分，见[验证记录](PROJECT-STATUS.md)。
